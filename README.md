# 🍁 Autumn

**Autumn** is a seasonal archive within Biohazalware dedicated to the preservation and study of historical malware and related software.

This collection brings together decompiled source code, technical documentation, and research material for educational and analytical purposes. By preserving older malicious software, researchers can examine the techniques, design patterns, and behaviors that shaped the development of modern cybersecurity.

All material is provided for **authorized research, reverse engineering, education, and archival purposes**. Samples should be treated as potentially harmful and examined exclusively within controlled, isolated environments.

Biohazalware does not claim ownership of original malware or source code unless explicitly stated.

> **Preservation enables understanding. Understanding enables defense.**
