# Biohazalware

Source code and malware samples in this repository were decompiled and documented by the Creator for research, educational, and archival purposes.

This project preserves decompiled source code for the analysis and study of historical malware and related software. The contents are provided to support reverse engineering, security research, malware analysis, and educational investigation.

The repository does not claim ownership of the original malware or its original source code unless specifically stated.

All published content is intended to comply with applicable GitHub policies and Terms of Service. Samples and source material should be handled responsibly and only in an appropriate, isolated research environment.

## Purpose

Biohazalware exists to:

* Preserve decompiled and historical malware source code.
* Support malware analysis and reverse-engineering research.
* Provide educational material for cybersecurity researchers.
* Document technical behavior and implementation details.
* Archive material that may otherwise become unavailable.

## Disclaimer

The contents of this repository may contain harmful or malicious code. Do not execute any samples on a personal computer or production system. The repository is intended for authorized research and educational purposes only.

The Creator does not encourage unauthorized access, harmful deployment, or malicious use of any material contained in this repository.

**Use responsibly.**
